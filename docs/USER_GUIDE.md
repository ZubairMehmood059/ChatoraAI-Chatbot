# Chatora AI User Guide

Welcome to **Chatora AI** — a premium, minimalist AI chatbot web application designed for focused thinking, productive drafting, and clear problem-solving.

---

## 1. Getting Started

When you open Chatora AI, you'll see the **Bento Grid Welcome Screen** with four prompt suggestions:
- **Learn something:** Explains difficult topics in simple, intuitive language with analogies.
- **Write better:** Drafts or improves emails, messages, proposals, or announcements.
- **Solve a problem:** Breaks down complex tasks into daily actionable steps.
- **Explore ideas:** Brainstorms innovative ideas and recommends where to start.

Clicking any card automatically populates the message composer and selects the bracketed placeholder text (e.g. `[topic]`), allowing you to immediately start typing your specific subject.

---

## 2. Managing Conversations

### Starting a New Chat
- Click the **New Chat** button at the top of the left sidebar.
- Or press the keyboard shortcut **`Alt + N`**.

### Searching Chats
- Use the **Search conversations** input at the top of the sidebar.
- Or press **`Ctrl + K`** (or **`Cmd + K`**) to immediately jump to search.
- Matching chats are filtered in real-time as you type.

### Renaming, Exporting, and Deleting Chats
Hover over any conversation in the sidebar or click the `...` menu button:
- **Rename:** Update the title of the conversation.
- **Export as Text (.txt):** Download the full transcript as a `.txt` file.
- **Export Markdown (.md):** Download formatted markdown with headings, code blocks, and timestamps.
- **Print conversation:** Open a clean print view formatted for paper or PDF export.
- **Delete chat:** Permanently removes the conversation and its history after confirmation.

---

## 3. Composing and Sending Messages

- **Send Message:** Press **`Enter`** or click the circular arrow button.
- **Multi-line Input:** Press **`Shift + Enter`** to add a new line without sending.
- **Stop Generating:** While the assistant is responding, the send button switches to a **Stop** button (square icon). Press it or hit **`Esc`** to halt response generation immediately.
- **Regenerate:** Click the **Regenerate** button below the assistant's last response to re-run the prompt.
- **Copy Message & Code:** Click the **Copy** button to copy responses or clean code blocks to your clipboard.

---

## 4. Attaching Documents

Click the paperclip button on the composer to attach text documents, markdown notes, or code files (`.txt`, `.md`, `.py`, `.js`, `.ts`, `.json`, `.csv`). The assistant will review the attached content and answer your questions directly from it.

---

## 5. Personalization and Settings

Click **Settings** in the bottom sidebar:
- **Theme:** Switch between **Light** and **Dark** modes. Your preference is saved locally.
- **Response Style:**
  - *Concise:* Direct, focused answers without filler.
  - *Balanced:* Clear, structured explanations with examples.
  - *Detailed:* In-depth, comprehensive analysis with edge cases and deep dives.
- **Data Deletion:** Clear all conversations permanently.

---

## 6. Keyboard Shortcuts

| Shortcut | Action |
| --- | --- |
| `/` | Focus the message composer |
| `Alt + N` | Start a new chat |
| `Ctrl + K` / `Cmd + K` | Search conversations |
| `Ctrl + \` / `Cmd + \` | Toggle the sidebar (expand/collapse) |
| `Esc` | Stop active generation or close modals |
| `Enter` | Send message |
| `Shift + Enter` | Insert line break |
